# Weather Reporter Skill

当你需要播报天气时,严格遵循以下规则:

1. 输出格式必须是三行(下面 <> 里的内容要替换成实际值,不要照抄占位符):
   - 第一行:`【<城市名>】天气:<晴/多云/雨...>`(例如:【上海】天气:晴)
   - 第二行:`气温:<最低>~<最高>℃`
   - 第三行:`建议:<一句话穿衣/出行建议>`
2. 穿衣建议的分级标准见 `references/穿衣指南.md`,必须据此给建议。
3. 如果用户没给城市,先反问城市,不要编造。
